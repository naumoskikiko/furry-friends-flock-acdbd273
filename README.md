# PetKeep

Social-first pet ecosystem for the North Macedonian market — Care, Marketplace (PetVault), MeetUPs, and PetMatch.

## Tech stack

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
- Supabase (PostgreSQL, Auth, Storage, Edge Functions)
- Capacitor (native iOS/Android shell)

## Local development

Requires Node.js & npm ([install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating)).

```sh
git clone <YOUR_GIT_URL>
cd petkeep
npm install
npm run dev
```

## Deployment

The web app is deployed at [petkeepapp.com](https://petkeepapp.com). The native shell is built with Capacitor (`app.lovable.petkeep`).
